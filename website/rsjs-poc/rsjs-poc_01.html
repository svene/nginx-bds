RSJS PoC

PoC goal: instead of having to use webcomponent bal-icon try to use the original html elements rendered by that webcomponent. Attach the behavior of the webcomponent through a script. A discoverer-script searches for elements with certain attributes (RSJS style) and attaches the original behavior. (open: is it possible to reuse the webcomponent behavior ?)

Example <bal-icon svg="balIconConsultant"...> to <div data-icon-svg="balIconConsultant" ...>

Script discovers elements with certain attributes and sets properties. This is in contrast to set the original attributes on the webcomponents.

<bal-icon data-icon-svg="..."> <div data-icon-svg="...">
